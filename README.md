
# Twister Survival

Twister Survival is a Java-based survival adventure game where players explore maze-like environments, interact with in-game notes and dialogue, and navigate through multiple levels. Players must explore their surroundings, follow clues, and overcome challenges as they progress through the game.

## Features

- **Maze Exploration** — Navigate through different environments and levels.
- **Interactive Notes** — Discover notes throughout the game to uncover information and clues.
- **Dialogue System** — Read in-game dialogue as the story unfolds.
- **Multiple Levels** — Progress through different stages of the adventure.

## Built With

- Java
- HSA Console Library

## Getting Started

### Requirements

- Java Runtime Environment (JRE) compatible with the compiled game.

### Running the Game

1. Download the game JAR file from the repository.
2. Open a terminal in the folder containing the JAR file.
3. Run the following command:

   ```bash
   java -jar ISP_PeterZhuangSohamMalla.jar
   ```
